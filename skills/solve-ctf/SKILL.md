# solve-ctf

One session per challenge. Intake records the challenge and creates its home **before**
solving starts; solving then continues in the same session with the notes kept current.

## 1. Intake

The intake command carries the challenge name, the statement, and optionally a target and
attachment paths. Chinese and English labels both work (`靶机`/`target`,
`附件`/`attachments`). The challenge name is the leading token.

From inside the competition workspace, run:

```bash
python <skill-dir>/scripts/intake.py "<the raw command>"
```

If you are not inside the workspace, add `--workspace "<workspace-dir>"`. The script:

- infers the category from the statement and creates
  `Challenges/<Category>/<challenge>/` with `notes.md`, `attachments/`, `solve/` and
  `session/`;
- records the statement verbatim, the target, the flag format, the hints, and any
  attachments (referenced by original path and copied into `attachments/`);
- suffixes the folder (`name-2`, `name-3`, …) when a name already exists in that category,
  so folders never merge.

**If it exits `3`**, the category was not confident. Ask the player which category is
right, then re-run with `--category <Misc|Web|Pwn|Crypto|Reverse|Forensics|OSINT|Malware|AI-ML>`.
Do not guess — a wrong category buries the challenge in the wrong folder.

A challenge with no attachments and no target is normal; the same flow applies.

## 2. Solve

Solve with your own capability. **Do not load a category skill** — `solve-ctf` carries the
whole flow (ADR-0006).

Before reaching for a tool, read the tools inventory at `tools.md` in this skill folder
(generated by `setup-ctf-skills`, listed in the workspace spec). It names the CLI tools and
MCP servers this machine actually has and how to invoke each. If a tool is not in the
inventory, ask before assuming it exists.

Keep working material in `Challenges/<Category>/<challenge>/solve/`. Put the script that
finally works there, so the solve is reproducible.

## 3. Keep the notes current *while* solving

`notes.md` is the durable record — the write-up must not depend on this conversation
surviving. Update it as you go, not at the end:

- **Observations** — key findings, parameters, versions, output that mattered.
- **Dead ends** — what you tried that failed, so it is not retried.
- **Tools & versions** — which tools and versions the solve depended on.
- **Script** — the working script (or its path in `solve/`).
- **Conclusion** — the short story of the solve.
- **Flag** — the flag, and set **Status** to `solved`.

Record the flag even if you are unsure it is accepted; the human submits it on the
platform (ADR-0003) and reports back. A rejected flag means the challenge goes back to
`unsolved`.

To update the notes reliably, use the bundled helper instead of hand-editing:

```bash
python <skill-dir>/scripts/note.py --challenge-dir <challenge-dir> \
  --section Observations --text "small e with no padding" \
  --section 'Tools & versions' --text "python 3.12, pycryptodome 3.20" \
  --script-file <challenge-dir>/solve/exploit.py \
  --field Status=solved --field "Flag=flag{...}"
```

`--append` adds to a section that already has content; without it, a non-empty section is
replaced. Unknown section or field names exit `6` without touching the file.

## 4. Hand off

When the flag is found, tell the player the flag and that they need to submit it. Do not
submit it yourself. Mention that `/organize-ctf-writeups` will turn the notes into the
write-up.

## Rules

- **Never log in to the platform, fetch challenges, or submit flags.**
- **Never load a category skill.**
- The statement is recorded verbatim — do not paraphrase it into the notes.
- Attachments are copied into the challenge folder so the solve survives the original
  download disappearing.
- Working material is disposable once the write-up exists.

## Install note

This skill resolves its bundled notes template relative to its own folder and prefers the
workspace's `templates/notes.md` when present. Keep `setup-ctf-skills` and `solve-ctf` as
sibling folders in the harness's skill directory.
